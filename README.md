# Usage Glance

One tiny macOS menu-bar app for AI usage. Usage Glance shows how your remaining Claude, Codex, and Cursor usage
compares with the time left in each limit window, as meters in the menu bar and a combined popover.

This repository hosts the signed, notarized downloads. The application source is developed privately.

## Install

Download the ZIP for your Mac from the [latest release](https://github.com/scottdflorida/usage-glance-releases/releases/latest)
— `arm64` for Apple silicon, `x86_64` for Intel — unzip it, and move `Usage Glance.app` to `/Applications`.
Releases appear here once signing is set up; until then there is nothing to download yet.

The app checks this repository for newer versions once a day and shows an Update button in its popover when one is
available. It sends nothing: the check is a single anonymous read of the latest release version.
