# UsagePool

This is where the signed, notarized downloads for UsagePool live. UsagePool is a little macOS menu bar app that shows
your AI usage limits for Claude, Codex, Cursor, GitHub Copilot, Muse Code and Antigravity (that one's still
experimental) against the time left before each one resets. The app's source is private, so this repo is just releases
and bug reports.

To get it, grab the DMG from [usagepool.ai/download](https://usagepool.ai/download) or from the
[latest release](https://github.com/Scott-Florida/usagepool-releases/releases/latest) here, open it, and drag UsagePool
into Applications. Once it's installed, updates come through the app itself (Settings → General), so you shouldn't need
to come back here for new versions. If you want to double-check a download, every file in a release has a `.sha256`
next to it, plus there's a `checksums.txt`.

If you've hit a bug you can make happen again, please [open an issue](https://github.com/Scott-Florida/usagepool-releases/issues/new/choose)
and the form will ask for the few things I need. Issues are public, so leave out your email, account or org names and
license key, and crop those out of screenshots too. Questions, ideas and anything about licenses, payments or refunds
go to support@usagepool.ai, and security problems go privately to security@usagepool.ai, never in an issue.
